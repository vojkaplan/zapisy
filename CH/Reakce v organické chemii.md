- typy:
	- substituce - jeden prvek se vymění za jiný
	- adice - přidá se celá část
	- eliminace - část se odebere
	- přesmyk - v jedné sloučenině se vymnění část
- substituci a adici leze dále dělit dle reakčních činidel na:
	- elektrofilní $E^+$
	- nukleofilní $Nu^-$
	- radikálové $R˚$ 
- $E^+$ a $Nu^-$ vznikají heterolytickým štěpením : A-B -> $A^+ + B^-$ 
	- např.: $H_2O$ -> $H^+ + OH^-$
- $R˚$ vzniká homolytickým štěpením : A-B -> A. + .B
	- např.: HCl -UV-> H. + .Cl
- Charakteristické názvy některých reakcí
	- Hydrogenace= reakce s vodíkem / Dehydrogenace = odštěpení vodíku
	- Hydratace = reakce s vodou / Dehydratace = odštěpení vody
	- Halogenace = reakce s halogenem
	- Nitrace = reakce s $NO_2^+$ (nitrační směs : $HNO_3$ + $H_2SO_4$ -> $NO_2^+$ + $H_2O$ + $HSO_4^-$ )
	- Sulforace = reakce s kys. sírovou $H_2SO_4$ 
- Oxidace/redukce
	- oxidace = zvyšování oxidačního čísla
	- redukce = snižování oxidačního čísla
- Mezomerní efekt
	- elektrofil - chce volný el. pár
	- elektrofob - nechce volný pár

### Alkany
- hl. zdrojem alkenů je ropa
- fyzické vlastnosti
	- první 4 plyny, dále kapaliny poté od 16 pevné látky
	- čím delší řetězec tím vyšší bod varu a tání
		- více větvení -> klesá bod varu
	- nepolární látky -> rozpustné v nepolárních rozpouštědlech
		- nerozpustí se ve vodě
		- dobře se v nich rozpouští další alkeny/nepolární sloučeniny
- připravují se: katalitickou hydrogenací nenasycených uhlovodíků
	- jde o redukci vodíkem
	- potřebuje katalizátor
	- k více vazebné sloučenině přidáme vodík -> jednoduše vazebná sloučenina
- reaktivita alkanů
	- málo reaktivní (nepolární vazby)
	- nejsou náchylné k heterolyckému štěpení vazeb (za vzniku bvou odlišně nabitých částic)
	- dříve označovány jako tzv. parafíni ("málo slučivé")
	- typickou reakcí je radikálová substituce (homolytické štěpení vazeb)
- radikálové reakce
	- probíhají za účasti radikálů
	- radikály - velmi reaktivní částice, lichý počet elektronů
	- probíhají tzv. řetězovým mechanismem
	- skládá se ze tří fází:
		- iniciace
			- dojde k homolytickému štěpení vazeb, vznikají 2 radikály
			- $X-X$ -UV> $X•+•X$
		- propagace (Horká brambora)
			- $CH_4 + CL•$ -> $CH_3• + HCl$
			- $CH_3•+Cl-Cl$ ->$CH_3Cl + Cl•$ 
		- terminace
			- $Cl•+•Cl$ -> $Cl_2$
			- inhibice = ukončení reakce pomocí nové látky 
	- jsou iniciovány vysokými teplotami, UV zářením nebo radikálovým činidlem
	- radikálová sulforace $CH_4 + Cl_2 + SO_2$ -> $CH_3SO_2Cl + HCl$ 
	- radikálová nitrace $CH_4 + HNO_3$ -> $CH_3NO_2 + H_2O$ 
	- Krakování = rozseknutí dlouhých řetězců
		- vznikají dva kratší (tam kde se sekne je dvojitá vazba)
